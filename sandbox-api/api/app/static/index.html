When you CREATE:
  1. name checked (idempotent - same name+spec returns the old one)
  2. a port from the pool is allocated (see the pool bar below)
  3. images pulled/built inside dind
  4. a private network + the template's containers start
  5. readiness check -> state READY
Every step appears live in the sandbox's event log.
When you DELETE:
  1. all its containers are force-removed
  2. its private network is removed
  3. its port returns to the pool
  4. state -> DELETED, but the event log stays (audit trail)
Deleting twice -> 404. Deleting while CREATING -> 409.
